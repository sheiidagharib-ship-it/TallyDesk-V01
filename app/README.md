# Tally Desk — Prototype (app)
Version: v1.0 · Date: 2026-11-13 · Time: 11:00 · Created by: Claude (asked by Nest)

## 1. What this is
A clickable desktop prototype (1440×900) of screens S1–S10 from "Approved — Wireframes v1.0.md", in the order of "Approved — Flows v1.0.md". Made-up app for practice. Values marked "sample data" are not evidence.

## 2. How to open (Windows)
From the project folder, in Command Prompt:
- Flow 1 (Persona 1, Freelancer): `start app\index.html` (opens S1)
- Flow 2 (Persona 2, Small company): `start app\S7-Overdue-overview.html`
Nothing to install. The font (Figtree) loads from Google Fonts; without internet a system font is shown.

## 3. Files
- `index.html` — opens S1 at once. Not a screen.
- `S1-…html` to `S10-…html` — one file per screen, copied unchanged from the HTML export (Tally Desk Canvas, exported 2026-11-13). S7 has its state switch (Default, Empty, Loading, Error).

## 4. Rules
- Only screens, text and data from the wireframes. No libraries.
- Code lives only in this folder. Research files stay in the project root.
